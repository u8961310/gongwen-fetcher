# 國尊公文附件下載器

自動把國尊公文系統收件夾的附件下載到本機，依「簽呈編號_簽呈主旨」建資料夾。

## 三步驟快速上手

1. **雙擊「安裝.bat」**（第一次才需要，需連網，約 5-10 分鐘）
2. **雙擊「首次設定.bat」**，依畫面輸入：登入網址 / 帳號 / 密碼 / 附件存放位置
3. **雙擊「執行.bat」**，開始下載附件

## 每天自動下載

雙擊「設定每日自動.bat」，即可設定每天早上 08:00 自動執行下載。
（如果顯示設定失敗，請對該檔案按右鍵「以系統管理員身分執行」再試一次。）

## 常見問題

1. **安裝失敗**
   通常是網路、防火牆或防毒軟體阻擋了下載 Node 或瀏覽器。請改用公司允許的網路，或聯絡資訊人員協助。

2. **執行後顯示登入失敗**
   多半是帳號、密碼或網址打錯了。請重新雙擊「首次設定.bat」再輸入一次正確資料。

3. **某公文沒有附件**
   這是正常情況，程式會顯示「無附件」並繼續處理下一筆，不影響其他下載。

4. **重複執行會不會重抓？**
   不會。已經下載過的公文會記在 `processed.json`，下次執行只會抓新的（增量下載）。

## 安全提醒

你的密碼以純文字儲存在本機的 `.env` 檔案中。請勿把整個資料夾分享、上傳或寄給他人，以免帳號密碼外洩。

## 給技術人員

本工具針對 **Cyberhood 線上簽核系統**。跨校使用時，各校的登入網址在「首次設定」步驟輸入即可共用同一套程式。

但若某校的系統為客製化或舊版、操作畫面與一般版本不同，則需依 `docs/selectors.md` 的說明，調整 `src/selectors.js` 中的元素定位設定後才能正常運作。
